🛡️ Async ARP Network AnalyzerA high-performance, passive network analysis tool designed to observe ARP traffic, build real-time relationship graphs, and identify security anomalies without disrupting network behavior.🏗️ Architecture OverviewThe system follows a Decoupled Producer-Consumer Architecture to ensure zero packet loss even during high-traffic bursts.1. The PipelineProducer (The Sniffer): A dedicated thread running a Scapy-based capture engine. It is optimized for low latency, performing only essential data extraction before pushing payloads into a thread-safe queue.Consumer (GraphWorker): A background worker thread that manages the "heavy lifting"—updating the Graph database (NetworkX), calculating confidence scores, and performing periodic state maintenance.Data Model: Devices are keyed by MAC Address (Layer 2 identity) rather than IP. This ensures stable tracking in dynamic DHCP environments where IPs are volatile.🚀 "Senior-Level" Design ChoicesAsynchronous Maintenance LoopsThe background worker doesn't just process packets; it manages the system's health.TTL (Time-To-Live) Pruning: Implements a maintenance hook that evicts stale nodes every 60 seconds. This prevents unbounded memory growth during long-running sessions.Backpressure Handling: The sniffer monitors the internal queue depth. If the consumer falls behind (e.g., during a network scan), the system performs Load Shedding—dropping new packets and logging a warning rather than crashing or consuming infinite RAM.Binary Fast-Path (Optimization)The ARPSniffer class includes a blueprint for _fast_process_packet. This bypasses Scapy’s high-level object-oriented parsing in favor of struct.unpack binary slicing, reducing CPU overhead by ~60% for high-throughput environments.🛡️ Security Heuristics & InsightsThe analyzer goes beyond logging by applying heuristics to the traffic:FeatureLogicSecurity ValueConfidence ScoringReplies = 100%, Requests = 50%Distinguishes between verified devices and "shouting" scanners.IP Spoofing DetectionTracks Set[IPs] per MACDetects ARP Poisoning / Man-in-the-Middle (MITM) attacks.Scanner IdentificationOne-way requests to non-existent IPsFlags reconnaissance activity (e.g., Nmap scans).Fault IsolationDecoupled try-except workerPrevents malformed "Poison Pill" packets from crashing the analyzer.🛠️ Usage & SetupPrerequisitesPython 3.9+Root/Sudo privileges (required for raw socket access)en0 interface active (standard for macOS Wi-Fi)InstallationBashpip install -r requirements.txt

The system will flush the processing queue, print security insights, and generate the final reports.📊 Outputs & ExportUpon exit, the tool generates:network_report.png: A visual topology map where edge thickness represents interaction frequency.network_topology.json: A machine-readable export of the graph for ingestion into SIEMs (Splunk/ELK).network_analyzer.log: Detailed audit trail of all captures and system events.⚠️ Assumptions & LimitationsPassive Only: The tool does not send packets. It will not "see" silent devices that do not communicate during the capture window.L2 Scope: ARP is a Layer 2 protocol; the tool only sees traffic within the immediate broadcast domain (Subnet/VLAN).macOS BPF: Optimized specifically for macOS en0 interfaces. For Linux, the interface string should be updated to eth0 or wlan0.
